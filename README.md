# Steamy Files Bot

Бот-хранилище для Telegram Mini App [Steamy Store](https://t.me/SteamyStore_bot?startapp). Файлы игр лежат в закрытом канале, бот только копирует их пользователю по ссылке `t.me/<имя_бота>?start=game_<id>`.

Идентификаторы совпадают с каталогом Steamy Store:

1. Subverse
2. Eternum
3. My Dystopian Robot Girlfriend
4. Goddesses' Whim
5. Maeve's Academy

## Запуск на Render

1. Создайте Web Service из этого репозитория.
2. Команда запуска: `npm start`.
3. Добавьте переменные окружения (см. ниже).
4. На Render бот сам включает webhook: берёт публичный адрес из `RENDER_EXTERNAL_URL` (Render задаёт её автоматически) и сообщает его Telegram. Новые сообщения приходят HTTP-запросом на сервис и **будят** бесплатный инстанс, если он уснул. Отдельная переменная для URL не нужна.
5. Ответ `Bot is alive` на `GET /` можно по-прежнему использовать для проверки или для пинга (например, cron-job.org каждые 10 минут) — тогда бот ответит быстрее после сна. Без пинга тоже работает: первое сообщение после сна может идти 10–30 секунд, Telegram обычно повторяет доставку сам.

Локально, без `RENDER_EXTERNAL_URL` и `WEBHOOK_URL`, бот запускается через long polling:


```bash
npm install
BOT_TOKEN=... ADMIN_IDS=123456789 npm start
```

## Переменные окружения

| Переменная | Обязательно | Описание |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | да, для команд | Telegram user id админов через запятую, например `123456789,987654321`. Узнать свой id можно у [@userinfobot](https://t.me/userinfobot) |
| `STORAGE_CHANNEL_ID` | рекомендуется | Id закрытого канала с файлами. Если не задан, используется значение по умолчанию `-1004302896014`. Лучше указать его в переменных Render. |
| `PORT` | нет | Порт HTTP-сервера, по умолчанию `3000` |
| `RENDER_EXTERNAL_URL` | нет | Render задаёт сам, например `https://steamy-files-bot.onrender.com`. По ней ставится webhook. |
| `WEBHOOK_URL` | нет | Если нужно задать публичный адрес вручную (без Render). |
| `WEBHOOK_SECRET` | нет | Секрет пути и заголовка webhook. Если не задан, берётся хеш от `BOT_TOKEN`. |
| `STORE_BOT_TOKEN` | нет | Токен бота магазина [@SteamyStore_bot](https://t.me/SteamyStore_bot). Если не задан, бот магазина не запускается, бот файлов работает как раньше. Не ставьте сюда тот же токен, что в `BOT_TOKEN`. |
| `STORE_WEBAPP_URL` | нет | HTTPS-адрес Mini App, по умолчанию `https://steamy-store.vercel.app`. Нужен для кнопки «Открыть магазин». |
| `STORE_RULES_CONTACT` | нет | Больше не используется для публичного контакта. В правилах и помощи показывается бот поддержки. |
| `RULES_CONTACT` | нет | Больше не используется для публичного контакта. В правилах и помощи показывается `@SteamySupportBot` или `SUPPORT_BOT_USERNAME`. |
| `SUPPORT_BOT_TOKEN` | нет | Токен бота поддержки. Если не задан, бот поддержки не запускается, остальные боты работают как раньше. Не ставьте сюда тот же токен, что у бота файлов или магазина. |
| `SUPPORT_BOT_USERNAME` | нет | Юзернейм бота поддержки, например `SteamySupportBot` или `@SteamySupportBot`. Если задан, в правилах и `/help` ботов магазина и файлов контакт меняется на него. |


Токен в репозиторий не кладите, только в настройки Render. Не запускайте локально тот же `BOT_TOKEN`, что на Render: long polling и webhook не должны работать одновременно.

## Канал и права бота

1. Создайте закрытый канал (уже есть, id `-1004302896014`).
2. Добавьте бота в канал как администратора. Ему достаточно права на просмотр сообщений; публиковать от имени бота не обязательно.
3. Файлы в канал загружайте **со своего аккаунта**, не через бота. Обычный аккаунт — до 2 ГБ, Telegram Premium — до 4 ГБ. Если архив больше, разрежьте его (7z или RAR) на части примерно по 1,9 ГБ и загрузите каждую отдельным постом.

Бот не скачивает эти файлы и не отправляет их как новую загрузку, а копирует готовые посты командой `copyMessage`. Поэтому лимит Bot API в 50 МБ на него не действует, и у пользователя не будет подписи «переслано из».

## Как привязать игру к постам

1. Загрузите архив (или части) в канал.
2. Перешлите пост боту в личку — он ответит номером поста. Либо откройте пост в Telegram Desktop: в конце ссылки на сообщение будет номер, например `.../12`.
3. Напишите боту: `/link 2 12 13 14` — для игры с id 2 и постов 12, 13 и 14 по порядку.
4. Бот пришлёт актуальный `files.json`. На Render диск временный, поэтому скопируйте этот JSON в файл `files.json` в репозитории и задеплойте ещё раз, иначе привязки пропадут после перезапуска.

Другие команды админа:

- `/files` — показать текущие привязки
- `/test 2` — отправить себе файлы игры 2, чтобы проверить

Если `ADMIN_IDS` не задан, команды админа никому не доступны.

## Ссылка из Mini App

Формат: `https://t.me/<имя_бота>?start=game_<id>`

Примеры:

- `https://t.me/<имя_бота>?start=game_1` — Subverse
- `https://t.me/<имя_бота>?start=game_2` — Eternum

Это параметр `start`, не `startapp`. `startapp` открывает Mini App, `start` отдаёт файл.

В Steamy Store кнопка «Скачать в Telegram» уже открывает такую ссылку. Бот отдаёт файлы только в личных сообщениях: если написать ему в группе, он попросит перейти в личку.

## Бот магазина @SteamyStore_bot

Отдельный процесс не нужен: если задан `STORE_BOT_TOKEN`, тот же сервис на Render отвечает и за @SteamyStore_bot. Webhook у него свой (`/webhook/store/...`), webhook бота файлов не меняется.

Повторные `/start`, `/help`, `/rules` и нажатие «Правила» заменяют предыдущий ответ того же типа: бот удаляет своё старое сообщение и команду пользователя, если получится, и присылает новое.

После деплоя добавьте в Render переменную `STORE_BOT_TOKEN` (токен именно магазинного бота, не файлового) и перезапустите сервис. Затем в @BotFather настройте текст для пустого чата:

**Команда `/setdescription` для @SteamyStore_bot (до 512 символов):**

```
Steamy Store — каталог игр для взрослых (18+).

Откройте магазин прямо в Telegram: карточки, скриншоты, ссылки на разработчиков и файлы в личку.

• Каталог внутри Telegram
• Канал новостей: @steamystore
• Игры принадлежат их авторам — поддержите разработчика, если понравилось

Нажмите Start, чтобы начать.
```

**Команда `/setabouttext` (до 120 символов):**

```
Каталог игр для взрослых (18+). Откройте магазин в Telegram, смотрите карточки и поддерживайте разработчиков.
```

**Картинка для пустого чата:** команда `/setdescriptionpic`. Возьмите логотип магазина: файл `public/logo-lockup-dark.webp` в репозитории steamy-store или https://steamy-store.vercel.app/logo-lockup-dark.webp. Если BotFather не примет WebP, сохраните его как JPG или PNG и загрузите его.

Не включайте webhook у других сервисов для того же `STORE_BOT_TOKEN`: у одного бота может быть только один webhook.

## Приветствие @SteamyFilesBot

При `/start` без параметра игры бот присылает картинку, короткий текст и кнопки «Открыть магазин», «Канал» и «Правила». Повторные `/start` без игры, `/help`, `/rules` и нажатие «Правила» заменяют предыдущий ответ того же типа: бот удаляет своё старое сообщение и команду пользователя, если получится, и присылает новое. Выдача файлов от `/start` с игрой не затрагивается. Кнопка магазина ведёт на `https://t.me/SteamyStore_bot?startapp` (Mini App принадлежит боту магазина, поэтому здесь обычная ссылка, а не `web_app`). Подпись с названием, версией и кнопками «Автору» и «Магазин» ставится прямо на первый файл; если так скопировать не получится, бот отправит файл как раньше и допишет подпись отдельным сообщением. Названия и ссылки лежат в `games.json`.

В @BotFather для @SteamyFilesBot настройте текст пустого чата:

**Команда `/setdescription` (до 512 символов):**

```
Steamy Files — бот, который выдаёт файлы игр из Steamy Store.

Чтобы получить игру, откройте магазин, выберите карточку и нажмите «Скачать в Telegram». Здесь только публичные версии, 18+.

Канал новостей: @steamystore
Игры принадлежат их разработчикам — если понравилось, поддержите автора.

Нажмите Start, чтобы начать.
```

**Команда `/setabouttext` (до 120 символов):**

```
Бот выдаёт файлы игр из Steamy Store. Откройте магазин, выберите игру и нажмите «Скачать в Telegram». 18+.
```

**Картинка 640×360 для пустого чата:** команда `/setdescriptionpic` или поле Welcome Picture в Edit Info. Файл: `assets/files-welcome.jpg` в этом репозитории.

## Бот поддержки

Отдельный процесс не нужен: если задан `SUPPORT_BOT_TOKEN`, тот же сервис на Render отвечает и за бота поддержки. Webhook у него свой (`/webhook/support/...`), webhook ботов файлов и магазина не меняется.

Человек пишет боту в личку, выбирает тему (реклама, помощь, правообладателям или другое) и отправляет текст, фото или файл. Бот пересылает это всем id из `ADMIN_IDS`: сначала шапку с темой, именем, юзернеймом, id и языком, затем само сообщение. Админ отвечает реплаем на шапку или на копию — бот отправит ответ человеку с пометкой «Ответ поддержки:». Запасной вариант: `/reply 123456789 текст`. После отправки бот напишет «✅ Отправлено» или причину ошибки, например если пользователь заблокировал бота.

Команды админа, в меню их нет:

- `/reply <id> <текст>` — ответить по номеру пользователя
- `/ban <id>` и `/unban <id>` — запретить или снова разрешить писать

Повторный `/start` заменяет предыдущее приветствие, как у других ботов. Чтобы получать обращения, каждый админ из `ADMIN_IDS` должен сам нажать Start у бота поддержки.

Защита от спама (админов не касается): не больше 3 сообщений в минуту и 20 в день; предупреждение приходит один раз за окно, а не на каждое лишнее сообщение. Если человек упирается в лимит три раза за 10 минут, бот сам глушит его на час, пишет ему об этом один раз и коротко сообщает админам id. `/unban` снимает и бан, и мут. Одинаковые сообщения подряд (тот же текст или тот же файл) в течение 10 минут бот молча игнорирует. Неизвестные и лишние команды пользователя удаляются из чата, повторные нажатия кнопок темы только закрывают «часики», без новых сообщений. Служебные ответы бота (приветствие, подсказка темы, «сообщение получено», «подождите» и уведомление о муте) заменяют предыдущие такого же типа и не копятся в чате; сообщения пользователя и ответы поддержки при этом не удаляются.

После деплоя добавьте в Render переменные `SUPPORT_BOT_TOKEN` и `SUPPORT_BOT_USERNAME` и перезапустите сервис. Затем в @BotFather настройте текст для пустого чата. Аватарку можно поставить ту же эмблему, что у канала и бота магазина (суккуб в пламени, файл `avatar-640.png` в оформлении канала).

**Команда `/setdescription` (до 512 символов):**

```
Steamy Store | Поддержка — бот, через который можно написать команде каталога.

Реклама, помощь, вопросы правообладателей и другие обращения. Нажмите Start, выберите тему и напишите сообщение. Мы ответим здесь же.

Каталог: @SteamyStore_bot
Канал: @steamystore
18+.
```

**Команда `/setabouttext` (до 120 символов):**

```
Поддержка Steamy Store. Нажмите Start, выберите тему и напишите сообщение — мы ответим здесь.
```

Не включайте webhook у других сервисов для того же `SUPPORT_BOT_TOKEN`: у одного бота может быть только один webhook.
